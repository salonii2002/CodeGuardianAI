# CodeGuardian AI

### Autonomous Multi-Agent Code Review & DevSecOps Platform

CodeGuardian AI is a developer-focused platform designed to improve code review and software security. It brings multiple specialized review agents together to help identify security vulnerabilities, code quality issues, missing tests, and documentation gaps.

The platform provides a centralized dashboard to inspect review activity, analyze findings, manage agents, and explore suggested improvements.

> **Project status:** Frontend demonstration. Backend services, real AI agent execution, and GitHub integration are planned for future development.

---

## Key Features

- **Dashboard:** View repository activity, pull requests, findings, and agent status.
- **Repository Management:** Explore and manage repository information.
- **Pull Request Management:** Review sample pull requests and their analysis status.
- **Live Analysis:** Explore code findings and their related source files.
- **Security Review:** Display sample security findings and severity levels.
- **Multi-Agent Management:** Configure and manage specialized review agents.
- **Knowledge Base:** Explore security and code review knowledge entries.
- **Evaluation:** Demonstrate test-case evaluation workflows.
- **Similarity Check:** Explore potentially duplicated code sections.
- **Cost & Usage:** View sample token usage and agent cost analytics.
- **Integrations:** Configure demonstration integration settings.
- **Activity Logs:** Explore project activity and reports.

## Specialized Review Agents

| Agent | Responsibility |
|---|---|
| Security Agent | Identifies potential security vulnerabilities |
| Code Quality Agent | Reviews code quality and maintainability |
| Test Gap Agent | Highlights missing test coverage |
| Documentation Agent | Identifies documentation gaps |

## Review Workflow

1. A developer opens or updates a GitHub pull request.
2. The backend receives and validates the webhook.
3. Changed files are collected for review.
4. Specialized review agents analyze the available evidence.
5. Security and code quality findings are consolidated.
6. Findings are displayed with severity and supporting evidence.
7. Developers inspect suggested improvements.
8. Human approval is required before proposed changes are applied.

## Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/salonii2002/CodeGuardianAI.git
```

Open the project folder:

```bash
cd CodeGuardianAI
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.

### Production Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## Current Project Limitations

This version focuses on the frontend experience.

- Dashboard information uses demonstration data.
- AI agents do not execute actual code analysis yet.
- GitHub repository connections are not live.
- Integration settings are demonstration-only.
- Evaluation results are not generated by a real AI model.
- Usage and cost values are sample metrics.

These features will be connected to backend services as development progresses.
